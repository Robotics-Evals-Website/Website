§ Format Required shape for every Stage 1 submission

A task instance is a distribution, not a scene.

A fixed scene measures memorisation. We fund benchmarks whose instances are recipes: named random variables with stated distributions, realised under seed. Running a policy across realisations estimates an instance success probability, P̂. Every Stage 1 application must include one instance in exactly this form.

kitchenbench / pour_pasta / measuring-cup-to-bowl Draft — not human-validated 
TaskInstance(
    instance_id = "pour_pasta/measuring-cup-to-bowl",
    goal        = "pour the dry pasta into the {vessel}",
    setup = {
        "vessel":         Categorical(("bowl", "cup", "pot")),
        "fill_g":         Uniform(80, 200),
        "pour_height_cm": Uniform(8, 15),
        "vessel_x_cm":    Normal(0.0, 3.0),
        "vessel_y_cm":    Normal(0.0, 3.0),
    },
    target_kind = "pour_into",
)
realize(seed=0) vessel        = bowl
fill_g        = 156
pour_height_cm = 9.9
vessel_x_cm   = +0.3
vessel_y_cm   = −1.6
realize(seed=2) vessel        = cup
fill_g        = 111
pour_height_cm = 10.1
vessel_x_cm   = −7.3
vessel_y_cm   = +5.4

5 instances per task  ·  5 realisations per instance  ·  accepted only at ≥ 4/5 from 3 independent raters on representativeness and quality
